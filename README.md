# Aestyve 홈페이지

## 📋 프로젝트 개요
에스티브(Aestyve) 공식 홈페이지 — 멀츠에스테틱 구조 기반 완전 리뉴얼  
폰트: **에스코어 드림 (S-Core Dream)** 전체 적용

## 🖋️ 에스코어 드림 폰트 굵기 설정

| 요소 | 굵기 | 값 |
|------|------|-----|
| 대제목 (Hero, Section Title) | Bold | 700 |
| 중제목 (Card, Subsection) | SemiBold | 600 |
| 헤더/네비/버튼 | Medium | 500 |
| 본문/설명 | Regular | 400 |
| 푸터/보조 텍스트 | Light | 300 |

## 📁 파일 구조
```
/
├── index.html       메인 홈페이지
├── admin.html       관리자 패널
├── css/
│   ├── style.css    메인 스타일 (S-Core Dream 적용)
│   └── admin.css    관리자 스타일
├── js/
│   ├── main.js      메인 인터랙션
│   └── admin.js     관리자 기능
└── data/
    └── content.json CMS 초기 데이터
```

## ✅ 구현 완료 기능
- 에스코어 드림 폰트 전체 적용 (300~700 굵기)
- 멀츠에스테틱 구조 기반 7개 섹션
- 히어로 자동재생 슬라이더 (3개)
- 제품 5개 실제 이미지 + Featured 블록
- 탭 필터 (ALL / NEW / BEST)
- 다국어 지원 (한국어 / 영어)
- 관리자 패널 완전 연동 (CRUD)
- JSON Export / Import / Reset
- 모바일 반응형
- 팝업 없음

## ⚙️ 관리자 접속
`/admin.html` — 헤더/푸터 ADMIN 버튼으로도 접근 가능
