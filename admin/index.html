Aestyve 관리자 연결

이 사이트는 GitHub Pages에서 호스팅되고 있어, 별도 서버 없이 GitHub 저장소에 직접 저장하는 방식으로 동작합니다.

토큰 만드는 방법 (최초 1회만)
1. GitHub 로그인 → 우측 상단 프로필 → Settings
2. 왼쪽 메뉴 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens
3. "Generate new token" 클릭
4. Repository access에서 이 사이트의 저장소만 선택
5. Permissions → Contents를 "Read and write"로 설정
6. 생성된 토큰(github_pat_로 시작)을 복사해 위에 붙여넣기

이 토큰은 이 브라우저에만 저장되며 Anthropic이나 다른 어떤 곳으로도 전송되지 않습니다. 공용 컴퓨터에서는 사용을 피해주세요.
