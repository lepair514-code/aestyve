Aestyve 관리자 최초 설정

여기서 입력하는 내용은 이 브라우저 안에서만 계산되며, 어디로도 전송되지 않습니다. 결과로 나오는 파일 하나만 저장소에 커밋하면 됩니다.

토큰 만드는 방법
GitHub 로그인 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access에서 이 저장소만 선택 → Permissions → Contents를 "Read and write"로 설정 → 생성된 토큰(github_pat_로 시작) 복사

1. 아래 내용을 admin/config.enc.json 파일로 저장소에 커밋해 주세요.

2. 다운로드한 config.enc.json 파일을 저장소의 admin 폴더 안에 넣고 커밋/푸시하세요.
3. 이후에는 admin/index.html (관리자 페이지)에서 방금 설정한 비밀번호만 입력하면 로그인됩니다.
4. 이 설정 파일에는 GitHub 토큰이 비밀번호로 암호화되어 들어있습니다. 방금 만든 비밀번호를 잊지 마세요 — 잊으면 이 페이지에서 새로 생성해 config.enc.json을 교체해야 합니다.
