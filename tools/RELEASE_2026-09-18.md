# Aestyve website release verification — 2026-09-18

## Included changes

- The homepage presents the supplied 3D carton label artwork, interactive
  Alpha/Beta/Gamma selection and composition panels with a CSS 3D fallback.
  Print colors are independent of HDR lighting; original artwork is unchanged.
- Home and brand pages share the same five-card horizontal glass carousel,
  equal dimensions, real product images, mouse drag, touch scrolling, keyboard
  access, previous/next controls and subtle pointer tilt.
- The new Face Studio introduction follows the main product hero. It uses the
  supplied translucent-face JPEG and original carton textures with layered
  glass information panels, pointer parallax, drag/button/keyboard product
  selection, and reduced-motion support. The head is illustrative artwork;
  its movement is a presentation effect, not a facial scan or analysis.
- All three HA detail pages include a compact Face Studio entry after the
  product introduction. All entry links open the existing Face Studio in a
  separate tab. Its existing frame restrictions are preserved; no iframe is
  used and the simulator, photo processing and security settings are unchanged.
- The three-language catalog-based HA studio retains product specifications,
  manufacturer data labels and source limitations, source imagery, interactive
  materials/data panels and the original Korean catalog download.
- Removed CMS authoring comments from public copy. Brand card copy matches the
  homepage overview. Fixed stale PLLA/INNOFill navigation and language links,
  restored three-language choices in PCL and Revibe navigation, and repaired
  legacy Revibe language links. Public 404 images have alternative text.
- Mobile menu state is exposed to assistive technology and Escape closes it.
  The contact email button now follows the editable EMAIL field while retaining
  the inquiry subject. No email was sent during verification.

The temporary responsive-review fixture is removed from the final release.
The iframe checks test responsive CSS layout, not physical iOS/Android devices.
The verification browser disables WebGL. The main hero's CSS 3D fallback is
verified, and its WebGL bundle builds; GPU rendering and the independently
hosted Face Studio's photo-to-3D editing could not be exercised here. Face Studio
correctly shows its existing unsupported-browser message in that environment.

## Reproduction and assets

Run `python tools/build-face-studio.py` to restore the shared entry sections.
The HA page generator calls it after rebuilding the three catalog pages.
The source `abstract-representation-futuristic-human-head-with-translucent-skin-against-soft-background.jpg`
is copied unchanged to `assets/face-studio/translucent-face.jpg`.
Shared effects are in `assets/face-studio.css` and `assets/face-studio.js`.
The site's existing `/facelab/` reverse proxy remains unchanged.

Production is delivered through the existing main-branch Git integration after
merging the verified design pull request. No domain, DNS, account or simulator
security settings are changed by this release.
