# Aestyve Face Lab 0.3 — 비공개 기술 테스트 배포 준비

## 사용자가 지금 할 일
ChatGPT의 Vercel 연결 카드에서 계정을 연결합니다. 비밀번호/API 키/환자 사진을 채팅에 보낼 필요가 없습니다. 도메인을 새로 구매할 필요도 없습니다. GitHub 개발 브랜치와 배포 파일은 준비되어 있지만, 연결 전에는 실제 웹 주소가 생기지 않습니다.

## 배포 담당 설정
- 저장소: lepair514-code/aestyve
- 개발 브랜치: feature/aestyve-simulator-mvp
- Root Directory: simulator
- Framework: Other
- Build Command: node scripts/build.mjs
- Output Directory: dist
- Node.js: 22 이상
- 기존 메인 홈페이지 프로젝트와 분리된 새 프로젝트를 사용합니다.
- 프리뷰 배포만 생성하고, Vercel Authentication과 접근 제한을 먼저 설정합니다. noindex와 CSP는 접근 인증을 대신하지 않습니다. 로그아웃한 별도 브라우저에서 프리뷰 보호를 확인합니다.
- 운영용 Production URL을 공개하지 않습니다. 요금제 업그레이드·유료 기능·도메인 구매는 별도 승인을 받습니다.

## 로컬 개발
Node.js 22 이상에서 simulator 폴더에 들어가 `npm run build`, `npm start`를 실행하고 `http://127.0.0.1:8080`을 엽니다. 첫 빌드에는 인터넷이 필요합니다. 빌드는 SDK/WASM/모델 6개를 dist/vendor에 가져옵니다. 하나라도 실패하면 배포 빌드는 실패합니다. 런타임의 사진은 서버로 전송하지 않으며 모델은 같은 사이트에서 받습니다. 폰트 CSS는 외부 CDN을 참조하고 폰트 파일은 배포 패키지에 포함하지 않습니다.

이번 버전은 검토된 v0.2 소스를 유지하고 build.mjs에서 정확한 앵커를 확인한 변환을 수행합니다. 변경된 소스에 앵커가 일치하지 않으면 자동 배포를 중단합니다. 실제 배포/브라우저 테스트 대상은 dist뿐입니다. 직접 루트 index.html을 여는 방식은 v0.3 실행 방법이 아닙니다.

## 추가한 내용
Vercel 빌드/보안 헤더, 모델 동일 출처 제공, 실패 시 중단하는 자산 빌드, 자산 해시 기록, 얼굴 사진 없는 환경 점검 페이지, 사진 삭제 후 정점 수 복원, 비교 이미지 저장 후 원래 표시 상태 복원, 브라우저 다운로드 호환 보완, 안전성 미확인 안내를 추가했습니다.

## 완료와 미완료의 구분
CI 결과가 나오기 전에는 자동 테스트 통과를 주장하지 않습니다. 브라우저 테스트는 실제 MediaPipe 모델과 공식 공개 샘플 사진을 사용하도록 작성했으며, 실행 보고서와 종료 상태로 성공 여부를 확인해야 합니다. SwiftShader WebGL 확인은 물리 GPU/아이폰 테스트를 대신하지 않습니다. 실제 환자 사진·다양한 피부톤·임상 정확도는 별도 검증 대상입니다.

실제 피부검사, 필요 시술 자동 판정, 주입량(mL)과 결과의 검증된 연결, 수분/유분/탄력 측정, 노화 예측, 완전한 머리 3D 스캔은 완성했다고 주장하지 않습니다. 제공 기능은 추정 얼굴 전면 3D의 임의 형태 탐색, 사진 색상 관찰, 사용자가 고른 고민에 연결한 일반 치료 정보입니다. 시술하지 않는 선택을 포함하며 의료진 검토를 대신하지 않습니다.

## 환자 공개 전 확인
의료진의 내용 검토 및 실제 사용 목적·의료기기/광고/개인정보 검토, 사용 동의와 보관 정책, 제품별 근거와 매핑, 실제 기기/동의받은 사진 테스트가 필요합니다. 허위 피부 점수나 검증되지 않은 제품 효과를 만들어 채우지 않습니다.

아직 도메인 구매, DNS 변경, main 병합, 환자용 공개를 수행하지 않았습니다.
