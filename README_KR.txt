AESTYVE SIGNATURE WEBSITE
=========================
색감 방향: Deep Navy + Warm Apricot + Ivory
참고한 톤: 사용자가 제공한 첫 번째 홈페이지 시안의 색감/레이아웃 무드.
구조와 카피는 Aestyve 브랜드 전략에 맞게 새로 설계했습니다.

FTP 업로드
1. ZIP을 압축 해제합니다.
2. 내부 파일 전체를 public_html / www / html 등 웹 루트에 업로드합니다.
3. assets 폴더 구조를 변경하지 마세요.

CSS / JS
- 별도 CSS 파일 없음: 각 HTML <style> 내부에 포함.
- 외부 JS 파일 없음: 각 HTML 하단에 최소한의 인라인 JS만 사용.

SEO 수정
- 각 HTML <head> 안의 'SEO EDIT ZONE' 주석을 검색하세요.
- title / description / canonical / og:image를 페이지별로 수정할 수 있습니다.
- sitemap.xml / robots.txt 포함.
- 추후 영문/중문 페이지 제작 시 hreflang 추가 권장.

연락처
- 현재 info@aestyve.com / Seoul, Republic of Korea 로 임시 설정.
- 실제 정보로 변경하려면 'EDIT CONTACT EMAIL' / 'EDIT COMPANY INFO' 검색.

사진
- 메인 히어로 모델 이미지는 사용자가 제공한 참고 시안의 우측 비주얼을 웹용으로 크롭한 임시 이미지입니다.
- 실제 오리지널 고해상도 캠페인 사진이 있으면 assets/hero_warm.webp를 교체하는 것을 권장합니다.
- Innofill PLLA는 공식 제품 사진이 없어 SVG 임시 비주얼을 사용했습니다.

규제/표현
- 인증, 임상, 시험 수치, 승인 기관은 실제 증빙 자료와 일치하는 경우에만 기재하세요.
- Exosome / NAD+ 등은 국가별 제품 분류와 허용 표현이 다를 수 있습니다.

⚠️ 필수 조건: 이 관리자 기능은 PHP(8.0 이상) + GD 확장이 활성화된 호스팅에서만 동작합니다.
   대부분의 국내 웹호스팅(카페24, 가비아, 닷홈 등)은 기본 지원합니다.
   업로드 후 https://aestyve.com/admin 접속이 안 되거나 500 오류가 뜨면,
   호스팅사에 "PHP 및 GD 확장 사용 가능 여부"를 문의해 주세요.

[텍스트 편집]
- 페이지별로 제목/본문/연락처/통계 문구 등 총 241개 항목을 수정할 수 있습니다.
- 항목을 수정하면 화면 하단에 "변경사항 저장" 바가 나타나며, 눌러야 실제로 저장됩니다.
- 저장 즉시 홈페이지 방문자에게도 반영됩니다(별도 배포/재업로드 불필요).
- 제목처럼 줄바꿈·강조색이 들어간 항목은 "줄바꿈 추가" / "선택 강조색 적용" 버튼으로 조절합니다.

[이미지 관리]
- assets 폴더의 모든 이미지가 썸네일로 표시됩니다.
- 썸네일을 클릭해 파일을 선택하거나, 이미지 파일을 그대로 끌어다 놓으면(드래그 앤 드롭)
  같은 자리(같은 파일명)에 즉시 덮어써져서 홈페이지에 바로 반영됩니다.
- 어떤 형식(JPG/PNG 등)으로 올려도 서버가 자동으로 기존 파일 형식에 맞게 변환합니다.
- 로고를 다시 바꾸고 싶다면 assets 목록에서 logo.webp를 교체하면 헤더/푸터에 동시 반영됩니다.

[보안 주의사항]
- /admin 폴더는 비밀번호로 보호되어 있지만, 그 외 별도의 접근 제한은 없습니다.
  가능하다면 호스팅 관리 콘솔에서 /admin 경로에 추가 접속 제한(IP 제한 등)을 걸어두면 더 안전합니다.
- content.json 파일은 텍스트 데이터 저장용으로 누구나 읽을 수 있습니다(비밀번호 등 민감정보 없음).
- 관리자 비밀번호는 주기적으로 변경해 주세요.
